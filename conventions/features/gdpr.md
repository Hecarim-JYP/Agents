# 레시피: 해외 이용자 — GDPR 적용 판단·쿠키 동의·국외 이전 `[대외]`

> 확정: 2026-10-19 | 원칙: consent.md(동의는 이력), privacy-rights.md(권리 요청 처리) | 짝: personal-data.md, seo.md(다국어·지역 대상 표시), i18n.md
> 먼저 **GDPR 적용 대상인지 판단해 기록**한다 — EU 안에 사업장이 없어도 EU 이용자에게 재화·서비스를 **제공하려 하거나** EU 안의 행동을 **추적**하면 적용된다. 적용되면 분석·광고 쿠키는 **동의한 뒤에만 불러오고**, 권리 요청은 한국 기한(10일)으로 처리해 양쪽 기한을 함께 지킨다. 한국 쪽에서는 해외 클라우드·도구로 개인정보를 넘기는 것이 **국외 이전**이다.

## 1. 언제 쓰나

해외 이용자가 가입·구매할 수 있는 서비스, 다국어(특히 EU 언어)·외화 결제·해외 배송을 제공하는 서비스. 국내 전용 서비스라도 **해외 클라우드·분석·메일 대행사**를 쓰면 1-2절(국외 이전)은 해당한다.

### 1-1. GDPR 적용 범위 (2026-10-19 — 검색 요약, 2차 출처)

| 항목 | 내용 | 출처 |
|---|---|---|
| 지역 적용 | EU에 사업장이 없는 처리자도 ⓐ EU 안의 정보주체에게 재화·서비스를 **제공**(유상·무상 불문)하거나 ⓑ EU 안에서의 **행동을 모니터링**하면 적용 | GDPR 제3조 ② — EDPB 지침 3/2018(2019-11 최종) 해설 기사 |
| 우연한 제공 | EU를 여행 중인 비EU 이용자에게 우연히 제공하는 정도로는 적용되지 않는다. **EU 위치 기반 타깃 광고**는 행동 모니터링에 해당할 수 있다 | 같은 출처 |
| 역내 대리인 | 제3조 ②로 적용되면 **EU 역내 대리인을 서면으로 지정** — 간헐적·저위험이고 대규모 민감정보 처리가 아니면 예외 | GDPR 제27조 해설 |
| 적정성 결정 | EU 집행위원회가 **2021년 12월 한국에 적정성 결정** — EU에서 한국으로의 개인정보 이전에 추가 보호조치(표준계약 등)가 필요 없다. **GDPR 적용 자체를 면제하는 것은 아니다** | EU 집행위원회 보도자료(IP/21/2964) 및 로펌 해설 |
| **미확인** | 권리 요청 응답 기한(1개월, 연장 가능), 유출 시 감독기관 신고 기한(72시간), 쿠키 동의 요건(ePrivacy 지침) — 검색 결과에 원문 근거가 없었다 | 착수 시 EUR-Lex 원문 확인 (MANDATORY) |

- 적용 판단은 **법무가 하고 결과·근거를 CLAUDE.md에 기록**한다 (MANDATORY) — 판단이 바뀌면(EU 언어 추가, EU 배송 시작) 다시 한다.

### 1-2. 한국 법 — 국외 이전 (원문 확인 2026-10-19 — legalize-kr)

| 항목 | 내용 | 근거 |
|---|---|---|
| 원칙 | 개인정보를 국외로 **제공(조회되는 경우 포함)·처리위탁·보관**하는 것이 "이전" — 원칙적으로 금지, 예외 요건 중 하나를 충족해야 한다 | 개인정보 보호법 제28조의8 ① (2026-09-08 공포본 — 이 조는 그 개정 대상 아님) |
| 계약 이행 예외 | 계약 체결·이행에 필요한 처리위탁·보관이면 **이전 항목을 처리방침에 공개**하거나 전자우편 등으로 알리면 된다 | 같은 조 ① 3호 |
| 알릴 항목 | 이전 항목 / 이전 국가·시기·방법 / 받는 자의 명칭·연락처 / 이용 목적·보유 기간 / 거부 방법·절차·효과 | 같은 조 ② |
| 기타 예외 | 별도 동의, 받는 자의 인증, **보호위원회가 동등 수준으로 인정한 국가** 등 | 같은 조 ① 1·4·5호 |

## 2. 결정 항목 (기본값)

| 결정 | 기본값 | 대안 / 비고 |
|---|---|---|
| GDPR 적용 | **시작 시 판단·기록** — 대상이 아니면 EU 언어·통화·배송을 제공하지 않는 것과 일관되게 | 대상이면 3절 전부 |
| 분석·광고 쿠키 | **동의 후에만 스크립트 로드**(EU 대상이면 필수, 아니어도 권장) — 필수 쿠키(세션·동의 기록)만 동의 없이 | 서버 측 집계(쿠키 없는 방문 통계) — 동의 배너가 필요 없는 구성 |
| 동의 기록 | 로그인 사용자 = consent.md 이력(`terms_type = 'COOKIE_ANALYTICS'`), 비로그인 = 동의 쿠키(6개월) | |
| 권리 요청 | privacy-rights.md 요청 테이블 그대로 — **한국 기한(10일)으로 처리** | EU 기한(1-1절 미확인 항목)이 더 길다면 한국 기한을 지키면 양쪽 충족 — 원문 확인 후 확정 |
| 처리방침 | 국외 이전 항목 공개(1-2절) + EU 대상이면 영어판, 법적 근거·대리인·보유 기간 명시 | |
| 역내 대리인 | 대상이고 예외가 아니면 지정 — 대행 서비스 계약 | |

## 3. 표준 설계

### 3-1. 적용 판단 체크리스트 (법무에 넘길 사실)

| 질문 | 확인할 곳 |
|---|---|
| EU 언어 화면·EU 통화 가격·EU 배송을 제공하는가 | i18n.md 설정, 결제·배송 설정 |
| EU 대상 광고·EU 위치 기반 개인화를 하는가 | 마케팅 채널, 추천 로직 |
| EU에서 가입·결제한 이용자가 실제로 있는가 | 가입 국가·결제 통화 통계 |
| 해외 클라우드·분석·메일·상담 도구에 개인정보가 들어가는가 (1-2절 국외 이전) | 인프라 구성, 외부 SDK 목록 |

### 3-2. 쿠키 동의 게이트

```js
// web/src/shared/consent.js — 분석 스크립트를 index.html에 직접 넣지 않는다. 동의한 뒤에만 동적으로 불러온다
const CONSENT_COOKIE = 'consent';

/** 동의 상태 — 'analytics' | 'none' | null(아직 묻지 않음) */
export const readConsent = () => document.cookie.match(/(?:^|; )consent=([^;]+)/)?.[1] ?? null;

/** 분석 스크립트 로드 — 한 번만 */
let loaded = false;
export function loadAnalytics() {
  if (loaded) return;
  loaded = true;
  const s = document.createElement('script');
  s.src = import.meta.env.VITE_ANALYTICS_SRC;      // 도구별 주소는 빌드 변수
  s.async = true;
  document.head.appendChild(s);
}

/** 배너의 선택 저장 — 동의 기록 자체는 필수 쿠키(동의 없이 저장 가능한 기능 쿠키)로 둔다 */
export function saveConsent(value) {
  document.cookie = `${CONSENT_COOKIE}=${value}; path=/; max-age=${60 * 60 * 24 * 180}; SameSite=Lax`;
  if (value === 'analytics') loadAnalytics();
}

// 앱 시작 시: readConsent() === 'analytics'면 loadAnalytics(), null이면 배너 표시, 'none'이면 아무것도 하지 않는다
```

- 배너: "동의"와 "거부"를 **같은 단계·같은 무게**로(거부만 설정 화면 깊숙이 두지 않는다), 기본 체크 없음, 화면 하단 고정 링크로 언제든 변경.
- 실측 2026-10-19 (Chromium 헤드리스, 쿠키 목록 확인):

| 구성 | 첫 화면 쿠키 |
|---|---|
| 분석 스크립트를 HTML에 직접 | **`_analytics_id` — 아무것도 누르기 전에 생성** |
| 동의 게이트, 첫 화면 | 없음 |
| 동의 게이트 + 거부 | `consent`만 |
| 동의 게이트 + 동의 | `consent`, `_analytics_id` |

### 3-3. 권리 요청·유출

- 권리 요청(열람·정정·삭제·처리정지·이동)은 privacy-rights.md의 요청 테이블·상태·통지를 그대로 쓴다. EU 이용자 요청은 영어로 접수·통지할 수 있게 화면·통지 문구를 다국어로(i18n.md).
- 개인정보 유출 대응 절차(감독기관·정보주체 통지 기한)는 한국 법과 GDPR을 함께 적은 대응표를 법무가 만들고 incident 절차(ops.md)에 연결한다 — 한국 법 기준 절차·기록은 privacy-breach.md, GDPR 기한 원문은 이 레시피에서 확인하지 않았다(1-1절).

### 3-4. 국외 이전 목록

- 개인정보가 들어가는 해외 서비스(클라우드 리전·백업 위치, 분석·메일·상담·결제 SDK)를 **목록으로 유지**하고 처리방침의 국외 이전 항목(1-2절 다섯 가지)과 맞춘다 — 외부 SDK를 추가하는 PR에서 목록 갱신을 확인 항목으로.

## 4. 함정 (STRICT)

| 함정 | 증상 | 처방 |
|---|---|---|
| 분석 스크립트를 HTML에 직접 | **동의 전에 분석 쿠키 생성** (실측) | 동의 후 동적 로드 (3-2절) |
| 거부를 기억하지 않음 | 방문마다 배너 / 실수로 다시 로드 | 거부도 `consent=none`으로 기억 |
| 적정성 결정 = GDPR 면제로 이해 | 대상인데 대리인·쿠키 동의·권리 처리를 빠뜨린다 | 적정성 결정은 EU → 한국 **이전**에 관한 것 (1-1절) |
| 해외 도구를 "위탁"으로만 보고 처리방침에서 누락 | 국외 이전 항목 미공개 (제28조의8 ②) | 3-4절 목록 ↔ 처리방침 대조 |
| "조회만 되니 이전이 아니다" | 국외에서 **조회되는 경우도 제공에 포함** (제28조의8 ①) | 해외 상담 도구·원격 지원도 목록에 |
| 동의 배너의 기본 체크·거부 숨김 | 유효한 동의로 보기 어렵다 (consent.md 4절과 같은 원리) | 기본 해제, 동의·거부 같은 단계 |
| 적용 판단을 기록하지 않음 | EU 언어 추가 같은 변경 때 다시 검토하지 않는다 | CLAUDE.md 기록 + 변경 시 재판단 |
